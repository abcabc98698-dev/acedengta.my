# Contributing to AceDengta

Thank you for your interest in contributing to AceDengta!

## Issues & Discussions

- Search existing issues before opening a new one.
- For bug reports, provide browser information, OS, and reproduction steps.
- For feature requests, share use-case details and rationale.

## Local Development

```bash
git clone https://github.com/acedengta/acedengta.git
cd acedengta
pnpm install
pnpm dev
```

Run checks before submitting PRs:
```bash
pnpm check
pnpm build
```
